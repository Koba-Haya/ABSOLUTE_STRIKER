# タイトルシーン 実装メモ(選択理由・代替案)

計画: [TITLE_SCENE_PLAN.md](TITLE_SCENE_PLAN.md) / 実装範囲: L0(必達)まで。L1 以降(雲・水しぶき・平面反射・レイマーチ)は未実装。
面接・発表の素材。各項目は「何を選んだか / なぜか / 代替は何か」。

## 全体構成

```
TitleScene   … 入力・時間・スタート演出の進行・描画順
 └ TitleDirector … 時間だけから「自機・カメラ・画角・ロゴ・フラッシュ板」の状態を返す(状態を持たない関数)
Renderer::DrawSky / DrawWater … 全画面パス(空・水面)
```

- 座標や秒数のベタ書きを `TitleScene` に置かず、`TitleDirector` の名前付き定数に集めた。シーンはその結果をモデルとカメラへ流し込むだけにして、クラスの肥大化を避ける。
- 本物の `PlayerComponent` は使わない。ゲームの自機と動きが衝突しないよう、見た目だけを使うタイトル専用の演出にした。

## L0-1 土台・ロゴ(3D モデル)

- **ロゴと PRESS START は板ポリの 3D モデル**にした。ImGui は `USE_IMGUI` で括られ Release では丸ごと消えるが、モデルは通常の 3D 描画なので Release でも出る。代替: ImGui のテキスト(Release で出ない)、2D スプライト(別パイプラインが要る)。
- 半透明の表示は `DrawEffectModel`(unlit・αブレンド・`depthWrite=false`)で行い、フェードや点滅は `SetColor` のα。Dissolve は不要だった。
- **OBJ の座標は読み込み時に Z が反転する**(`aiProcess_MakeLeftHanded`)。ファイル上で z=-0.5 の点は、エンジン内では z=+0.5。板ポリの左右反転、自機の前後逆はこれが原因だった。素材は `gen_*.py` で生成し、Blender で開いて書き出し直さない(座標が変わる)。
- PRESS START の明滅は `0.5 + 0.5·sin(2πt/周期)` を 0〜1 に直し、下限(0.25)まで線形補間。周期は定数。

## L0-2 空(`Sky.VS/PS`, `Sky.hlsli`)

- **全画面三角形**(頂点バッファなし): 頂点 (-1,1)(3,1)(-1,-3) の 1 枚で画面を覆う。四角形 2 枚より頂点が少なく、継ぎ目の斜め線も出ない。
- **視線方向の復元**: 画面位置を NDC にし、z=0(近い面)と z=1(遠い面)の 2 点を `invViewProj` でワールドへ戻し、差を正規化する。1 点では位置しか分からず向きにならない。逆行列は `Inverse(view × proj)`、行列は行優先(`row_major`)で C++ と一致させる。
- **深度**: VS が z=1 で出力し、深度は `LESS_EQUAL`・`depthWrite=false`。深度バッファのクリア値は 1.0 で、`LESS` だと `1.0<1.0` が偽になり空が描かれない。描画順に依らず常に最奥になる。
- **色**: 高さ `pow(dir.y, 0.6)` で地平線(霞)→中間→天頂の 2 段階補間。太陽は視線と太陽方向の内積(cos)で、広いグロー(`pow 8`)・近いグロー(`pow 96`)・円盤(`smoothstep`)。RTV が sRGB なので、シェーダーはリニア値で書く。
- 空の色関数は `Sky.hlsli` に切り出し、水面の反射からも呼ぶ。空と水面の色が自動で揃う。
- 当初は夕焼けだったが、昼の空へ変更(色定数のみの差し替えで済んだ)。

## L0-3 水面(`Water.PS`, `Water.hlsli`)

- **メッシュを使わず、全画面パスで「視線と水面(y=0)の交点」をピクセルごとに計算**した。計画の「カメラ追従の平面メッシュ」から変更。交点距離 `t = (カメラ高さ − 水面高さ) / (−dir.y)`、交点 `カメラ位置 + dir·t`。端が見えず、地平線は計算上ちょうど `dir.y=0` で空と繋がる。欠点は水面が深度を持たないこと(深度を読む演出はやらない方針)。カメラが水面に近づくと `t→0`、水面より下では破綻するので、カメラの高さに下限(0.4)を入れた。
- **波は交点のワールド XZ でサンプル**する。カメラが動くと模様は世界に固定されたまま後ろへ流れ、低空飛行の速度感になる。
- **波の法線**: 方向・周波数・振幅の違う `sin` を 4 本足した高さ関数の勾配(`cos`)から解析的に作る。遠いほど揺れを弱める(`1/(1+0.04t)`)のは、細かい波をピクセル単位で拾うとちらつく(エイリアシング)ため。
- **フレネル(Schlick)** `F = F0 + (1−F0)(1−N·V)^5`、`F0=0.02`。浅い角度ほど反射が強く、水平線近くが空色の鏡になる。反射方向は `reflect(dir, N)` で、下向きは `abs` で折り返して `SkyColor` を呼ぶ。
- 太陽の照り返しは `pow(dot(反射, 太陽), 256)`、波の揺れできらめく。遠方は霞(地平線の空色へ `1−exp(−0.012t)`)。
- 代替: 頂点変位メッシュ(VS に時間を渡す経路が要る)、ノイズ画像の法線マップ(テクスチャのバインドが要る)。屈折・海底・泡は深度読み取りが必要で効果が薄いので省いた。

## L0-4 演出(`TitleDirector`)

- **自機は時間の連続な式**: 前進(+Z)は一定速度、左右は `sin` の S 字、バンクは左右速度(位置の微分)に比例、進行方向は `atan2(vx, 前進速度)`。24 秒で時間を戻すと位置と水面の波位相が飛ぶので、カットだけ 24 秒でループし、自機の位置は絶対時間のままにした。
- **カメラは 4 カット × 6 秒**: ①ローアングル(進路の脇・前方に固定、自機が奥から手前へ通過)、②後方追従、③横トラッキング(バレルロール)、④回り込み。カット内は `smoothstep` のイーズ付き補間、カット間は編集で瞬間切り替え。スプラインは、位置の式が連続なので不要だった。
- **ロゴはカメラの基底(右・上・前)に取り付ける**: ワールド行列の各行は「モデルの x/y/z がワールドのどの向きか」+位置。カメラの右・上・前を入れると、どのカットでも画面の同じ位置に正対する。カメラのすぐ前(3 ユニット)に置くことで、深度テストでも必ず自機より手前になる(自機はカメラから常に 4 以上離れる)。
- 画角が広がっても画面上の大きさが変わらないよう、ロゴ類は `tan(fov/2)` の比で補正する。

## L0-5 スタート演出

- SPACE / ENTER / パッド A で、自機が `u²` で加速して飛び去る(はじめゆっくり、だんだん速く)。カメラは自機の余分な移動の 35% だけ追うので、自機が離れていき、引きながら画角が広がる。ロゴは上へ、PRESS START は下へスライドして消える。後半から白い板(カメラの目の前)のαを `smoothstep` で上げ、1.6 秒後に一度だけ `SceneId::Game` へ遷移する。
- 画面遷移の作り込みは別課題(10/14)なので、ここは白フラッシュ程度の最小限にした。

## 自機モデル

- 最終的に Tripo で生成した飛竜(約 3 万三角形、テクスチャ 2048²)を使う。最初は自作の仮モデル(`gen_striker_model.py`)。ポリゴン数は、画面に映る大きさが数百ピクセルなので、1.5〜3 万(上限 5 万)で十分。
- 立ち姿のモデルを飛行姿勢にするため、ボーンとウェイトを入れた `art/dragon/dragon_rig.blend` を用意した。自動ウェイトは複雑なメッシュで失敗しやすいので、距離ベースで自前計算(`gen_dragon_rig.py`)。標準ポーズは翼を後ろへ約 40° 振り、頭を 70° 持ち上げる。ポーズ付けは `.blend` で行い、`export_dragon_pose.py` で `dragon.obj` へ書き出す。
- 失敗例: 翼を 1 枚の板として剛体回転させると、扇状の指が胴体に重なって潰れた。指ごとにボーンを持たせて解決。
